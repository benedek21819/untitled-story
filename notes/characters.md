# Characters

## Template

Copy this block per character.

### Name

- **Role:** protagonist / antagonist / supporting
- **Wants:** the conscious goal they'd state out loud
- **Needs:** the thing they actually lack (often contradicts the want)
- **Flaw:** what makes them the wrong person for this
- **Arc:** where they start → where they end
- **Voice:** how they speak, what they never say
